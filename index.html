Vitund package index

A PEP 503 package index serving the Python client libraries for Vitund Sandboxes — vitund-cli (the vtd command-line client) and vitund-sdk (the generated SDK it is built on).

No releases have been published yet. The index is live but empty; the command below will find nothing until the first release lands. 

pip install --extra-index-url https://vitund-ai.github.io/pypi/simple vitund-cli

These are 0.x, pre-1.0 releases and the API is not frozen. Expect breaking changes; do not pin production systems to them yet.
